      to delete the referenced EMPLOYEE row.

======================================================================
Q1.3  If mgr_ssn and Dno are both NOT NULL, how do we insert the first
      row in EMPLOYEE or DEPARTMENT?
======================================================================


SQL:
    DROP DATABASE IF EXISTS company_q13;
    CREATE DATABASE company_q13;
    USE company_q13;

    CREATE TABLE emp  (ssn CHAR(9) NOT NULL, Dno INT NOT NULL, PRIMARY KEY (ssn));
    CREATE TABLE dept (Dnumber INT NOT NULL, mgr_ssn CHAR(9) NOT NULL,
                       PRIMARY KEY (Dnumber),
                       FOREIGN KEY (mgr_ssn) REFERENCES emp(ssn));
    ALTER TABLE emp ADD FOREIGN KEY (Dno) REFERENCES dept(Dnumber);

    INSERT INTO emp  VALUES ('999999999', 1);
    INSERT INTO dept VALUES (1, '999999999');

Output (both fail):
0	94	23:21:05	INSERT INTO emp VALUES ('999999999', 1)	Error Code: 1452. Cannot add or update a child row: a foreign key constraint fails (`company_q13`.`emp`, CONSTRAINT `emp_ibfk_1` FOREIGN KEY (`Dno`) REFERENCES `dept` (`Dnumber`))	0.000 sec
